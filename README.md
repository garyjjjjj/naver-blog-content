# 네이버 블로그 원고함

## 관리 프로그램 소스와 수정 이력

Windows 관리 프로그램 소스는 [app/](app/)에 보관합니다. [사용 안내](app/README.md), [변경 기록](app/CHANGELOG.md), [개발·검증 방법](app/DEVELOPMENT.md), [현재 구현·연결 상태](app/docs/STATUS.md)를 함께 관리합니다. 아래 수동 작업 안내와 별도로 GitHub 원고 감지는 구현됐으며, 공개 무인 발행과 MCP 자동 수정 루프는 아직 구축 중입니다.

로그인 세션·비밀번호·토큰·작업 DB·운영 로그·실행 파일은 소스 커밋에 포함하지 않습니다.

뮤즈 AI는 자료 수집과 최종 원고·이미지 준비를 담당하고, Codex는 지정된 글을 네이버 블로그에 입력하고 결과를 기록합니다.

## 폴더 구조

```text
MUSE_INSTRUCTIONS.md               # 뮤즈에 전달할 납품·발행 관리 지침
templates/post.md                  # 전달 정보 양식 (본문 구성은 자유)
posts/<뮤즈계정별명>/<글ID>/post.md # 완성 원고와 발행 정보
posts/<뮤즈계정별명>/<글ID>/images/ # 원본 이미지
```

예: `posts/muse-01/2026-10-19-001/post.md`, `images/01-cover.jpg`.
계정별명은 muse-01, muse-02처럼 지정하고 이메일·비밀번호를 기록하지 않습니다.
GitHub는 빈 폴더를 저장하지 않으므로 글과 이미지를 올리면 해당 폴더가 생성됩니다.

## 뮤즈 AI에 전달할 지시문

> 이 저장소의 MUSE_INSTRUCTIONS.md를 읽고 완성 원고와 이미지를 전달하세요. 글의 구성·문체·분량·소제목·이미지 배치는 뮤즈가 결정하세요. templates/post.md는 발행 정보와 본문 경계를 전달하기 위한 양식이며 글쓰기 틀이 아닙니다.

자세한 지시사항: [뮤즈 전달·발행 관리 지침](MUSE_INSTRUCTIONS.md). Codex는 뮤즈가 정한 제목과 본문 구성을 유지하고 네이버 편집기에 옮깁니다. 별도 요청 없이 문장을 재작성하거나 도입·소제목·마무리를 추가하지 않습니다.

뮤즈에서 GitHub로 직접 저장하려면 각 뮤즈 계정에 별도의 GitHub 연동이 필요합니다. 이 저장소를 만드는 것만으로 자동 연결되지 않습니다.

## 사용 순서

1. 양식을 복사하고 원고와 이미지를 준비합니다.
2. 사용자가 원고와 발행 설정을 확인한 후 status를 ready로 바꿉니다.
3. Codex에 저장소와 정확한 글 경로를 알려주고 작업을 요청합니다.
4. 기본 작업은 임시저장입니다. 공개 발행·예약은 사용자 요청과 설정이 모두 확인된 경우 진행합니다.
5. 실제 결과를 확인한 뒤 status와 result를 기록합니다. 실패하면 published로 표시하지 않습니다.

요청 예: `posts/muse-01/2026-10-19-001/post.md를 읽고 원고는 바꾸지 말고 네이버 블로그에 임시저장해줘.`

## 상태와 중복 방지

- draft: 작성 중
- ready: 사용자가 작업 대상으로 확정
- saved: 네이버 임시저장 완료
- scheduled: 네이버 예약 설정 완료, 아직 공개 발행 아님
- published: 공개된 게시글과 URL 확인 완료
- blocked: 로그인·편집기·이미지 등 문제로 미완료

동일 글ID 또는 결과 URL이 있는 글은 새 글로 다시 발행하지 말고 먼저 결과를 확인합니다. GitHub 파일이 생겼다고 자동 실행되지는 않습니다. 감지·예약 실행은 별도 설정이 필요합니다.

## 이미지와 원고

본문의 `![설명](images/파일명.jpg)`는 네이버 편집기에 해당 위치로 이미지를 첨부하라는 표시입니다. Markdown 서식은 편집기에 맞게 적용하며 파일 경로 자체를 공개 본문에 붙이지 않습니다. 출처 URL과 이미지 사용권을 기록하고, 누락된 이미지·미정인 블로그 주소를 임의로 채우지 않습니다.

저장소가 공개이면 원고와 이미지도 공개됩니다. 비공개 여부를 확인한 뒤 콘텐츠를 저장하세요. 로그인 비밀번호·인증코드·토큰은 저장하지 않습니다.
