# 변경 기록

## 0.1.0 — 2026-10-19 · 최초 소스 등록

이번 커밋은 아래 개발·수정 사항을 포함한 최초 GitHub 등록입니다. 이전 작업을 각각 과거 Git 커밋으로 재현하지 않았습니다.

### 관리 기능

- 로컬 관리 UI: 대시보드, 원고함, 뮤즈·카테고리, Codex AI 설정, 연결·자동 실행, 활동 기록.
- 실제 Codex App Server에서 5시간·주간 잔여율, 초기화 시각, 지원 모델·추론 강도 조회.
- 일반/심화 진단 모델 설정 저장과 사용량 보호 기준, 최근 24시간 진단 시도 제한.
- GitHub 커밋을 고정한 원고 감지, 이미지와 metadata 검증, 기존 발행 글 중복 처리 방지.
- 시작·일시정지·정지 및 재시작 후 상태 유지.
- Windows 바탕화면 설치, 로그인 후 자동 시작, 로그인 전 부팅 작업 등록 도구.

### 안정성·보안

- 로컬 Host/Origin 검사와 제어 토큰, Windows DPAPI 세션 암호화, 제한된 데이터 폴더 권한.
- 게시글 대조 증거와 완료 상태를 하나의 트랜잭션에 저장.
- 결과 불확정 자동 재시도 금지, 수정본의 기존 게시글 번호 유지 검증.

### 네이버 로그인 수정

- 동봉 Chromium의 Windows side-by-side 실행 오류를 확인하고 설치된 Google Chrome을 우선 사용하도록 수정.
- 전용 로그인 프로세스 오류를 상태 파일·관리 화면·로그에 전달하고 중복 실행 방지.
- 로그인 성공 시 세션 저장 후 별도로 글쓰기 화면 접근 확인.
- 실제 전용 로그인 저장 및 글쓰기 접근 확인 완료. 공개 발행은 수행하지 않음.

### 검증과 남은 작업

- Windows에서 단위/통합 검증 테스트 13개 및 설치 Chrome 실행 점검.
- 브라우저 발행·본문/이미지 입력·기존 글 수정 어댑터, MCP 서버, 두 뮤즈의 자동 수정 왕복은 미완료.
- 로그인 전 부팅 작업 자격 증명 등록과 실제 재부팅 시험 미완료.

## 이후 기록 방법

코드 수정 시 이 파일에 변경 이유, 바뀐 동작, 검증 결과와 미검증 범위를 추가합니다. 운영 상태는 `docs/STATUS.md`에 갱신합니다. 실행 파일 배포 이력과 소스 수정 이력을 구분하고 세션·토큰·작업 DB·로그는 커밋하지 않습니다.
