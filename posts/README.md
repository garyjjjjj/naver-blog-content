# 글 저장 위치

각 글은 `<뮤즈계정별명>/<글ID>/post.md`와 같은 폴더의 `images/`에 저장합니다.

```text
posts/
  muse-01/
    2026-10-19-001/
      post.md
      images/
        01-cover.jpg
        02-detail.jpg
  muse-02/
    2026-10-19-002/
      post.md
      images/
        01-cover.jpg
```

위 경로는 예시입니다. 실제 글은 ../templates/post.md를 복사해 만드세요. 계정별명을 늘려 여러 뮤즈 계정의 결과물을 구분할 수 있습니다. 글ID는 저장소 전체에서 중복되지 않게 지정하세요.
