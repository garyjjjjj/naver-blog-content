![클로드로 코딩 배우는 법](images/01-hero.jpg)

말만 하면 AI가 코드를 짜주는 시대다.
그런데 결과물이 나오고 나면 막힌다.
조금만 고치려 해도 처음부터 다시 시켜야 한다.
만든 사람이 코드를 모르기 때문이다.
**코드를 짜는 역할과 그 코드를 설명해주는 역할을 AI에게 함께 맡기면, 결과물도 나오고 내 실력도 쌓인다.**
클로드와 무료 웹 에디터 p5.js만 있으면 오늘 바로 시작할 수 있다.

> **핵심은 하나다. AI에게 결과물만 시키면 배우는 게 남지 않는다. 코드를 짜는 개발자 역할과 그 코드를 쉽게 설명해주는 선생님 역할을 함께 맡기면, 결과물도 나오고 내 실력도 쌓인다. 클로드와 무료 웹 에디터 p5.js만 있으면 오늘 바로 시작할 수 있다.**

클로드를 처음 써보는 사람이라면 [클로드 무료로 시작하는 방법](https://blog.naver.com/3700708/224474079288)에서 계정 만들고 첫 대화를 여는 순서를 먼저 확인하는 게 좋다.

```blog
type: heading
level: 2
runs:
  - text: "바이브코딩은 왜 배우는 데 실패할까?"
    style: {bold: true, color: "#007aa6"}
```

**시키기만 하니까 코드 내용을 모른다. 고치려면 처음부터 다시 부탁해야 한다.**

![바이브코딩은 왜 배우는 데 실패할까](images/02-img1.jpg)

바이브코딩은 말로 시키면 AI가 코드를 짜주는 방식이다.
결과물은 금방 생긴다.
그런데 문제가 있다.
**시키기만 하니까 만든 사람이 코드 내용을 모른다.**
조금만 고치려 해도 처음부터 다시 부탁해야 한다.

코딩은 한 번에 끝나는 작업이 아니다.
만드는 것도 만드는 거지만, 그걸 계속 발전시키고 운영해야 한다.
그래서 최소한 어떤 부분이 어떤 역할을 하는지, 어디를 바꾸면 무엇이 달라지는지는 알아야 한다.
그걸 모르면 **결과물은 AI의 것이고, 내 것은 남지 않는다.**

해법은 이름부터 다르다.
'두 역할 AI 코딩'이다.
AI에게 두 가지 역할을 시키는 것이다.
하나는 코드를 만들어주는 개발자 역할, 다른 하나는 그 코드를 내게 설명해주는 선생님 역할이다.
만들어주는 역할만 맡기면 바이브코딩과 똑같아진다.
**설명해주는 역할이 붙어야 배우는 코딩이 된다.**

```blog
type: heading
level: 2
runs:
  - text: "클로드와 p5.js로 두 역할 코딩을 시작하는 방법은?"
    style: {bold: true, color: "#007aa6"}
```

**예제 코드 하나를 클로드에 붙여넣고 "아주 쉽게 설명해줘"라고 물으면 된다.**

![클로드와 p5.js로 시작하는 방법](images/03-img2.jpg)

준비물은 두 가지다.
클로드와 p5.js 웹 에디터다.
p5.js는 그림을 그리는 코드를 웹에서 바로 써보고 돌려볼 수 있게 만든 도구다.
editor.p5js.org에 들어가면 **설치 없이 바로 쓸 수 있고, 무료다.**
왼쪽에 코드를 쓰고 재생을 누르면 오른쪽에 그림이 나온다.

시작은 예제 하나를 고르는 것이다.
p5.js 예제 중 점균류 시뮬레이션을 고르면 된다.
점균류는 실제 자연에서 먹이를 찾을 때 그물망 같은 길을 만드는 미생물이다.
이걸 코드로 옮기면 **혈관이나 나뭇가지 같은 패턴이 화면에 저절로 생긴다.**

예제 코드를 통째로 복사해 클로드에 붙여넣고 "이 코드를 설명해줘"라고 물으면 된다.
이때 한 가지를 덧붙인다.
"나는 아주 초보자다. 코딩을 전혀 모른다. 아주 쉽게 설명해줘."
그러면 클로드는 어려운 설명 대신 이야기로 풀어준다.

개미 4,000마리를 화면에 풀어놓는다고 상상하면 된다.
개미 한 마리는 단순한 규칙 세 가지만 따른다.

```blog
type: text
runs:
  - text: "살피기 — "
    style: {bold: true, color: "#ff008c"}
  - text: "앞쪽 세 방향을 살펴보고 그중 밝은 쪽으로 방향을 튼다"
```

```blog
type: text
runs:
  - text: "한 걸음 — "
    style: {bold: true, color: "#ff008c"}
  - text: "방향을 튼 뒤 한 걸음 앞으로 간다"
```

```blog
type: text
runs:
  - text: "흰 점 — "
    style: {bold: true, color: "#ff008c"}
  - text: "지나간 자리에 흰 점을 하나 남기고, 그 점은 시간이 지나면 서서히 흐려져 사라진다"
```

이 단순한 규칙만으로 화면에는 그물망이 저절로 생긴다.

코드 구조도 두 덩어리로 나뉜다.
setup은 프로그램이 켜질 때 딱 한 번만 실행되는 준비 부분이다.
draw는 1초에 60번씩 끝없이 반복되는 부분이다.
draw 안의 내용이 계속 다시 실행되면서 조금씩 달라지니까 그림이 움직이는 것처럼 보인다.
함수는 명령을 묶어 이름을 붙인 덩어리다.
**이 두 가지만 알면 코드가 왜 움직이는지 감이 잡힌다.**

바이브코딩으로 만든 웹사이트가 어떻게 구성되는지 궁금하면 [바이브코딩으로 만든 웹사이트 티어표](https://blog.naver.com/3700708/224475162723)에서 결과물을 고치는 기준을 참고할 수 있다.

```blog
type: heading
level: 2
runs:
  - text: "숫자만 바꾸면 내 작품이 되는 이유는?"
    style: {bold: true, color: "#007aa6"}
```

**바꿀 숫자가 한곳에 모여 있고, 숫자마다 뜻이 적혀 있기 때문이다.**

![숫자만 바꾸면 내 작품이 되는 이유](images/04-img3.jpg)

설명까지 들었으면 이제 내 작품으로 바꿀 차례다.
클로드에 이렇게 요청한다.
"어디를 어떻게 고쳐야 하는지 코드에 담아서 다시 작성해줘."
그러면 클로드는 주석을 가득 담은 코드를 다시 만들어준다.
주석은 슬래시 두 개(//)로 시작하는 줄이다.
컴퓨터는 건너뛰고 사람만 읽는다.
AI에게 주석을 많이 달아달라고 하면 **내가 읽을 수 있는 코드**가 된다.

새 코드에는 '조절판'이라는 구역이 따로 있다.
바꿔야 할 숫자 10개가 전부 거기 모여 있다.
각 숫자가 무슨 뜻인지, 작게 하면 어떻게 되고 크게 하면 어떻게 되는지가 한 줄씩 적혀 있다.
혈관, 실크, 소용돌이, 홍채 같은 레서피 4개도 들어 있다.
그대로 옮겨 적는 것부터 시작하면 된다.

가장 먼저 만져볼 숫자는 두 개다.
개미 마릿수와 센서 각도다.
개미를 4,000마리에서 500마리로 줄이면 길이 성긴 실선이 되고 패턴이 덜 복잡해진다.
2,000마리로 늘리면 다시 촘촘해진다.
센서 각도를 45에서 25로 바꾸면 개미가 앞을 보는 방향이 좁아져 패턴이 달라진다.
센서 거리 50도 같은 방식으로 바꿔볼 수 있다.

```blog
type: text
runs:
  - text: "숫자 하나만 바꿔도 화면이 바로 바뀐다."
    style: {bold: true, background: "#FFF3CD"}
  - text: " 고치는 재미가 바로 느껴지는 이유다."
```

에러가 나도 겁먹을 필요가 없다.
빨간 에러 문구를 그대로 복사해 클로드에 붙여넣으면 된다.
HTML 파일 전체를 붙여넣으면 에러가 난다.
p5.js 웹 에디터의 sketch.js는 자바스크립트만 받는데 HTML 코드까지 같이 들어갔기 때문이다.
클로드는 원인을 쉽게 설명해주고 자바스크립트 부분만 따로 뽑아준다.

```blog
type: text
runs:
  - text: "에러 문구를 복사해 붙여넣는 게 에러를 고치는 첫 단계다."
    style: {bold: true, background: "#FFF3CD"}
  - text: " 에러는 실패가 아니라 고치는 연습이다."
```

마지막 단계는 지침을 저장하는 것이다.
클로드에 "개발자 역할과 선생님 역할을 지침으로 적어줘. 다음 대화부터 바로 시작할 수 있게 해줘"라고 요청하면 된다.
그러면 다음부터는 처음부터 설명을 반복하지 않고, 바로 두 역할이 적용된 코드를 짜준다.
**새로운 AI 대화를 열 때마다 이 지침을 붙여넣으면 된다.**

```blog
type: heading
level: 2
runs:
  - text: "마무리"
    style: {bold: true, color: "#007aa6"}
```

AI가 코드를 짜주는 시대에, 정작 내 실력이 남지 않는다는 게 뼈아픈 지적이었다.
나도 결과물만 받아들고 "됐다"고 생각한 적이 있었다.
이제는 숫자를 하나씩 바꿔보며 내 손으로 고쳐보는 게 코딩 공부의 시작이라는 걸 알겠다.

## 자주 묻는 질문

**코딩을 전혀 몰라도 시작할 수 있나요?**
할 수 있다.
클로드에 "나는 초보자다. 아주 쉽게 설명해줘"라고 먼저 말하면 된다.
p5.js 웹 에디터는 설치 없이 브라우저에서 바로 쓸 수 있다.

**p5.js는 돈이 드나요?**
들지 않는다.
editor.p5js.org에서 무료로 쓸 수 있는 웹 에디터다.
설치도 필요 없다.

**바이브코딩과 두 역할 코딩은 뭐가 다른가요?**
바이브코딩은 결과물만 시키는 방식이다.
두 역할 코딩은 코드 짜는 역할과 설명해주는 역할을 함께 맡기는 방식이다.
결과물도 나오고, 그 코드를 내가 읽고 고칠 수 있게 된다.

**에러가 나면 어떻게 하나요?**
빨간 에러 문구를 그대로 복사해 클로드에 붙여넣으면 된다.
원인과 고친 코드를 함께 알려준다.
에러는 실패가 아니라 고치는 연습이다.

**다음부터 매번 설명을 반복해야 하나요?**
아니다.
두 역할 지침을 한 번 만들어 저장해두면, 새 대화에서 지침을 붙여넣는 것만으로 바로 시작할 수 있다.
